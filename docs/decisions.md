# Décisions d'architecture (1 ligne datée par décision)
- 2026-08-01 : Init du template. Stack Next.js + Supabase + Vitest + Playwright.
- 2026-08-01 : Stack scaffoldée dans le template (Next 16.2.12 / React 19.2.4 / Tailwind 4 / Vitest 4 / Playwright 1.62) + `package-lock.json` commité, pour que la CI soit verte dès le premier commit d'un nouveau projet. Contrepartie : versions à rafraîchir ~tous les 6 mois.
- 2026-08-01 : CI — gate `npm audit` bloquante sur `critical` au lieu de `high` : Next tire `postcss` et `sharp` avec des avis *high* dont le seul correctif proposé est un downgrade en Next 9. À réévaluer à chaque bump de Next.
- 2026-08-01 : Pas de `next/font/google` dans le layout — évite un appel réseau au build et une source de flakiness CI.
- 2026-08-01 : Tests unitaires dans `tests/` (Vitest + jsdom), e2e dans `e2e/` (Playwright). Playwright build et démarre l'app lui-même quand `CI=true`, `npm run dev` en local.
- 2026-08-01 : Seuils de couverture à 0 dans le template, à monter à 80/80 au premier ticket métier. Un template n'a pas de code métier : tout seuil > 0 est arbitraire et rend le repo rouge au repos, ce qui apprend à ignorer l'alerte. Corollaire : ne jamais baisser un seuil déjà atteint. Écarté : exclure `layout.tsx` de la couverture (pente savonneuse — on finit par exclure ce qui gêne) et écrire un test bidon sur le layout (ne prouve rien).
- 2026-08-01 : Scan de secrets du pre-commit limité aux lignes ajoutées (`grep '^+' | grep -v '^+++'`). Avant, il scannait tout le diff — contexte et suppressions inclus — et se détectait lui-même : éditer le hook près de la ligne du pattern faisait entrer cette ligne dans le diff en contexte et bloquait le commit sur un faux positif. Scanner les seules lignes ajoutées est aussi le bon périmètre sur le fond : on ne fuite un secret qu'en l'ajoutant.
- 2026-08-01 : Littéraux du scanner de secrets écrits en classes de caractères (`ROL[E]`, `live[_]`). Scanner les lignes ajoutées ne suffisait pas : les littéraux cherchés sont écrits dans le fichier scanné, donc toute modification du hook ajoutait une ligne qui matchait. La classe de caractères laisse la regex strictement équivalente mais casse l'auto-référence. Écarté : exclure le hook de son propre scan (angle mort permanent sur le seul fichier où un secret collé passerait inaperçu).
- 2026-08-01 : Scan de secrets insensible à la casse (`grep -qiE`) : la variante majuscules d'`api-key` passait au travers.
- 2026-08-01 : Gate local = gate CI. Le pre-commit lance `npm test -- --run --coverage`, exactement comme la CI : un gate local plus laxiste garantit des pushs cassés. Quand le seuil monte, les deux montent ensemble.
